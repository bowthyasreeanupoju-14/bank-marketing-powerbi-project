# Bank Marketing Power BI Dashboard (Task 3)

## 📊 Project Overview
This project analyzes a bank marketing campaign dataset using Power BI to understand customer conversion behavior.

## 🎯 Objective
To identify key factors influencing customer subscription decisions.

## 🛠 Tools Used
- Power BI
- DAX
- Data Visualization

## 📌 Key Features
- 5 Interactive Visualizations
- 3 KPI Cards (Contacts, Conversions, Conversion Rate)
- Age Group vs Conversion Analysis
- Job & Education Impact Analysis
- Previous Campaign Outcome (Donut Chart)
- 4 Interactive Slicers

## 💡 Key Insights
- Age group 25–34 shows higher conversion rate  
- Job type significantly impacts subscription  
- Previous campaign success increases conversions  
- Education level influences customer response
